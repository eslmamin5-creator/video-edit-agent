# video-edit-agent — دليل المستخدم

*الإصدار 0.2.2. هذا دليل موجّه للمستخدم — للتفاصيل التقنية والمعمارية انظر
`agent/core_instructions.md` وتعليقات التوثيق داخل وحدات `src/`.*

هذا هو مصدر Markdown القابل للتعديل لدليل الـ PDF
(`docs/video-edit-agent-user-guide-ar.pdf`، المُولَّد عبر
`scripts/build_user_guide.py`). عدّل هذا الملف، وليس الـ PDF مباشرة.

## إيه هو video-edit-agent؟

`video-edit-agent` (أمر سطر الأوامر: `videoedit`) وكيل مونتاج فيديو
بالذكاء الاصطناعي، يضع اللغة العربية أولاً، ولا يرتبط بمزوّد نموذج واحد.
تتكلم معاه بلغة عادية — عبر Claude Code أو مباشرة من سطر الأوامر — وهو
يحوّل تسجيل خام، أو سكربت، أو مجلد مشاهد، لفيديو جاهز ومترجم. يعمل بالكامل
دون اتصال بدون أي مفتاح API، ويتحسّن (ولا يعتمد أبدًا) على مزوّدين سحابيين
اختياريين (Gemini، ElevenLabs).

التجربة المفروض تحس بيها كالتالي:

> افتح Claude Code ← ثبّت/شغّل video-edit-agent ← اتكلم بشكل طبيعي ← اعمل فيديوهات

مش كالتالي:

> اقرأ توثيق تقني ← احفظ أوامر CLI ← افهم تفاصيل الحزمة الداخلية

## سير العمل الثلاثة: Editor / Creator / Assembler

مش لازم تختار الأمر بنفسك — قول اللي عندك واللي عايزه، والوكيل هيوجّه
طلبك. بس مفيد إنك تعرف شكل كل واحد:

### Editor — عندك تسجيل خام واحد
استخدمه لما يكون عندك تسجيل واحد بالفعل (حديث مباشر، إعلان، مقابلة) محتاج
تنظيف وصقل. Editor: يفرّغه، يكتشف ويقصّ الصمت/التكرار/البدايات الفاشلة،
يبني خطة مونتاج (EDL) قابلة للتعديل، يولّد ترجمات واعية بالعربي أو
الإنجليزي (تشكيل RTL، تظليل كلمات على طريقة الكاراوكي)، يخطط ويضع المواد
الإضافية (B-roll)، يطبّق رسوم متحركة (بما فيها الوضع خلف الشخص لو في قناع
صالح)، يطبّق هويتك التجارية، يجري فحص جودة، ويصدّر الفيديو النهائي.

الأمر: `videoedit edit <video>`

### Creator — عندك سكربت أو فكرة، من غير تصوير لسه
استخدمه لما تبدأ من سكربت مكتوب أو فكرة موصوفة. Creator يحلّل السكربت،
يخطط المشاهد، يحلّل الإيقاع والبنية، يبني لوحة قصة (storyboard)، يخطط
المواد اللي محتاجها، يجمّع MasterTimeline، يطبّق معالجة حركة، يصدّر، ويجري
فحص جودة.

الأمر: `videoedit create <script>`

### Assembler — عندك كذا مشهد/مقطع موجود بالفعل
استخدمه لما تكون صوّرت كذا مشهد بالفعل وعايز تجمعهم في فيلم واحد.
Assembler يكتشف المشاهد، يحافظ على الترتيب اللي تقصده، يبني قصة أولية
سريعة (`--rough`)، ثم يخطط الاستمرارية ويتم بانتقالات حقيقية وتلاشي صوت
متقاطع وتطبيع مستوى الصوت (`--finish`) — مع إعادة استخدام خطة القصة
الأولية بدل ما يبدأ من الصفر.

الأمر: `videoedit assemble <scenes_dir> --rough` ثم `--finish`

## نظرة عامة على الميزات

**ذكاء المونتاج** — مونتاج مبني على النص المفرَّغ؛ معالجة الصمت والتكرار
والبدايات الفاشلة؛ خطة مونتاج (EDL) قابلة للفحص وإعادة التصدير (غيّر قرار،
أعِد التصدير، من غير ما تعيد خط الأنابيب كله)؛ ذاكرة `project.md` دائمة
توضح قرارات الوكيل وأسبابها.

**العربية** — ترجمات RTL؛ تشكيل عربي؛ تظليل كلمات على طريقة الكاراوكي؛
الحفاظ على المصرية/الخليجية/السعودية/الفصحى؛ نصوص عربي/إنجليزي مختلطة في
نفس السطر؛ بدون أي تحويل لهجة مخفي، أبدًا.

**الحركة (Motion)** — محرك حركة بسيط مدمج يعمل دون اتصال دائمًا؛ تصدير
Remotion اختياري لحركة أغنى؛ تراجع تلقائي للمحرك (مُسجَّل، وليس صامتًا
أبدًا)؛ تقرير حالة التركيب خلف الشخص؛ أسلوب مرتبط بالهوية التجارية.

**المواد الإضافية (B-roll)** — تخطيط مع بدائل تلقائية للمزوّدين؛ مسار كامل
دون اتصال بمكتبة محلية؛ تحسين سحابي اختياري (توليد صور/فيديو Gemini) عند
توفر المفاتيح.

**ملفات الهوية التجارية (Brand Profiles)** — ألوان وخطوط وأنماط ترجمات
قابلة لإعادة الاستخدام لكل هوية، محفوظة كمجلدات عادية تحت `brands/<name>/`؛
بدون أي تعديل في الشيفرة المصدرية لإضافة واحدة.

**دون اتصال / السحابة** — شوف الجدول تحت لمعرفة بالظبط إيه اللي يعمل بدون
أي مفتاح مقابل إيه اللي تضيفه السحابة. لا يتم طبع أو تسجيل أو كتابة أي سر
في ملف إعدادات أبدًا.

**قابلية الفحص** — كل مرحلة ملف عادي تقدر تفتحه مباشرة: `project.md`،
النص المفرَّغ، خطة المونتاج، MasterTimeline، خطط الحركة/المواد/الجودة،
والفيديو النهائي.

## تجربة العربية أولًا

أهم قاعدة في المشروع: **الوكيل يفرّغ بالضبط ما قيل ولا يترجم أو يعيد كتابة
أو يصلّح أو يحوّل اللهجة العربية المنطوقة أبدًا.** المصرية، الخليجية،
السعودية، الفصحى، والكلام المخلوط عربي/إنجليزي كلها تُحفظ حرفيًا. الصوت
المصدر هو المرجع النهائي.

ده مستقل تمامًا عن اللغة اللي بتكلم بيها الوكيل. لو كتبت لـ Claude Code
بالعربي، ردود الوكيل نفسه (الإعداد، الحالة، الشرح، تقارير الإنجاز) بترجع
بعربي طبيعي ومفهوم — مش فصحى متكلّفة، ومش ترجمة حرفية من قالب إنجليزي. لو
كتبت بالإنجليزي، بترجع بالإنجليزي. في الحالتين، نص فيديوك وترجماته
مايتأثروش أبدًا بالاختيار ده.

## دون اتصال مقابل السحابة

| القدرة | تعمل بدون أي مفتاح API | إيه اللي بتضيفه السحابة |
|---|---|---|
| التفريغ | نعم — Faster-Whisper محليًا | تفريغ Gemini / ElevenLabs (اختياري، يحتاج مفتاح API) |
| الترجمات (RTL، تشكيل، تظليل الكاراوكي) | نعم، بالكامل محليًا | — |
| المونتاج (صمت/تكرار/بدايات فاشلة، EDL) | نعم، بالكامل محليًا | — |
| الرسوم المتحركة | نعم — محرك بسيط مدمج | Remotion (يحتاج Node/npm، بدون مفتاح API) لحركة أغنى |
| المواد الإضافية (B-roll) | نعم — مكتبة/تخطيط محلي | توليد صور/فيديو Gemini لمواد بالذكاء الاصطناعي |
| فحص الجودة البصري | نعم — فحوصات محلية أساسية | رؤية Gemini لفحص جودة أغنى |
| ملفات الهوية، EDL، التصدير، Assembler (أولية/إتمام) | نعم، بالكامل محليًا | — |

`GEMINI_API_KEY` و `ELEVENLABS_API_KEY` تُقرأ فقط من متغيرات البيئة، أبدًا
من ملف إعدادات، ولا تُطبع أو تُسجَّل من أي أمر — بما في ذلك
`videoedit doctor`.

## التثبيت عبر Claude Code

1. استنسخ (clone) أو ثبّت هذا المستودع داخل مجلد مهارات (skills) الخاص
   بـ Claude Code.
2. افتح Claude Code (أو أعد تشغيله).
3. قل: **"Set up video-edit-agent and verify it."**

يقوم Claude بإعداد كل شيء: يكتشف نظام التشغيل وإصدار بايثون متوافق (يفضّل
3.11)، يبني بيئة تشغيل خاصة يملكها المشروع (`.runtime/venv` — أبدًا بايثون
النظام)، يثبّت الحزمة الجاهزة للعمل دون اتصال، يتحقق من `ffmpeg`/`ffprobe`
وNode/npm، ويعرض تقرير جاهزية واضحًا باللغة اللي بتكلمه بيها. لا يُثبِّت
أبدًا برمجيات على مستوى النظام دون إذن — لو `ffmpeg` مفقود، يعطيك الأمر
الدقيق المناسب لنظامك وينتظر منك تشغيله بنفسك. لا يُطلب أو يُخزَّن أي مفتاح
API أبدًا.

## أمثلة أول استخدام

بمجرد ما الإعداد يعلن الجاهزية، اتكلم معاه عادي. أمثلة:

عربي ← Editor: `عدل الفيديو ده وخليه أسرع وأنضف`، `حط كابشن عربي وحافظ على
اللهجة المصرية`
عربي ← Creator: `اعمل فيديو من السكربت ده`
عربي ← Assembler: `اجمع المشاهد دي واعمل rough cut`
عربي ← غيره: `طبّق البراند ده على الكابشن والموتشن`، `اشتغل Offline فقط`

إنجليزي ← Editor: "Edit this video and make it faster and cleaner"
إنجليزي ← Creator: "Create a video from this script"
إنجليزي ← Assembler: "Assemble these scenes into a rough cut"
إنجليزي ← غيره: "Apply this brand to the captions and motion"، "Work
offline only"

لو طلبك مش واضح فعلًا، الوكيل هيسألك سؤال توضيحي واحد قصير بدل ما يخمّن.

## جولة في Editor

```bash
videoedit edit my_take.mp4
```

المخرجات في `my_take_edit/` بجانب الفيديو المصدر: `final.mp4`،
`transcript_unified.json`، `edl.json`، `captions.ass`، `project.md`، وملفات
خطط الجودة/المواد/الحركة. استخدم `--brand <name>` لتطبيق هوية تجارية،
و`--offline` لإجبار الوضع دون اتصال تمامًا.

## جولة في Creator

```bash
videoedit create my_script.txt
```

ينتج لوحة قصة، خطة مواد، MasterTimeline، وفيديو نهائي مُصدَّر، بنفس نمط
الملفات القابلة للفحص المستخدم في Editor.

## جولة في Assembler

```bash
videoedit assemble my_scenes_dir --rough
videoedit assemble my_scenes_dir --finish
```

`--rough` يبني معاينة سريعة مع الحفاظ على ترتيب مشاهدك. `--finish` يعيد
استخدام هذه الخطة لإضافة انتقالات حقيقية، وتلاشي صوت متقاطع، وتطبيع مستوى
الصوت للفيلم النهائي. تقدر تستأنف مشروعًا غير مكتمل بأمان.

## ملفات الهوية التجارية (Brand Profiles)

```bash
videoedit brand init my_brand
videoedit brand validate my_brand
videoedit edit my_take.mp4 --brand my_brand
```

ملف الهوية التجارية مجرد مجلد عادي تحت `brands/<name>/` يحتوي الألوان،
الخطوط، قائمة الكلمات الممنوعة، محرك الحركة المفضل، ونمط الترجمات.

## المخرجات وملفات المشروع

كل مرحلة في خط الأنابيب ملف عادي، ليس حالة مخفية أبدًا:
`project.md` (سبب كل قرار اتخذه الوكيل)، `transcript_unified.json`،
`edl.json`، `captions.ass`، ملفات خطط الحركة/المواد/الجودة بصيغة JSON،
و`final.mp4`.

## استكشاف الأخطاء / Doctor

```bash
videoedit doctor
```

يعرض جدول القدرات الكامل (ffmpeg، Node، المزوّدون، المحركات) بالإضافة إلى
ملخص آخر تشغيل لـ `videoedit setup`. شغّل `videoedit setup --check` لفحص
جاهزية للقراءة فقط، أو `videoedit setup --repair` لإعادة بناء بيئة التشغيل
الخاصة من الصفر بدون المساس بأي شيء خارج `.runtime/`.

## القيود المعروفة

- التعرف الصوتي (ASR) على كلام عربي حقيقي وتصدير Remotion لم يتم التحقق
  منهما بعد باختبارات قبول حقيقية في هذه البيئة — انظر جدول حالة القدرات
  في الـ README لتفاصيل الصدق الكاملة.
- قصّات J-Cut/L-Cut نظرية فقط، غير منفَّذة.
- HyperFrames ليس محرك حركة حقيقي قابل للتثبيت؛ الموجّه يتراجع دائمًا إلى
  محرك يعمل ويسجّل التراجع — وليس استبدالًا صامتًا أبدًا.

## الملحق التقني: أوامر CLI

| الأمر | الوظيفة |
|---|---|
| `videoedit edit <video>` | خط الأنابيب الكامل: تفريغ ← قص ← ترجمة ← مواد إضافية ← حركة ← تصدير ← جودة |
| `videoedit create <script>` | سكربت ← لوحة قصة ← خطة مواد ← حركة ← تصدير ← جودة |
| `videoedit assemble <scenes_dir> --rough` | قصة أولية سريعة من مجلد مشاهد مصوَّرة مسبقًا |
| `videoedit assemble <scenes_dir> --finish` | إتمام بانتقالات حقيقية + تطبيع الصوت |
| `videoedit doctor` | عرض جدول القدرات |
| `videoedit providers` | عرض مزوّدي التفريغ والحركة وتوفرهم |
| `videoedit setup [--profile ...] [--check] [--repair]` | إعداد بيئة التشغيل الخاصة والتحقق من الجاهزية |
| `videoedit config show / set` | عرض أو تعديل الإعدادات (بدون أي أسرار) |
| `videoedit brand init / validate` | إنشاء أو التحقق من ملف هوية تجارية |
| `videoedit project inspect <dir>` | عرض ذاكرة `project.md` لمشروع ما |
