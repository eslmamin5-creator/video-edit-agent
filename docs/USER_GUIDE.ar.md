# video-edit-agent — دليل المستخدم

*الإصدار 0.2.2. ده دليل موجّه للمستخدم — للبنية التقنية والداخليات شوف
`agent/core_instructions.md` وتوثيق الموديولات تحت `src/`.*

ده مصدر Markdown القابل للتعديل لدليل الـPDF
(`docs/video-edit-agent-user-guide-ar.pdf`، بيتولّد بواسطة
`scripts/build_user_guide.py`). عدّل الملف ده، مش الـPDF.

## video-edit-agent

video-edit-agent وكيل مونتاج وإنتاج فيديو بالذكاء الاصطناعي داخل Claude
Code. تكلمه بلغتك العادية — عربي أو إنجليزي — وهو بيحوّل التصوير الخام، أو
السكربت، أو فولدر مشاهد، لفيديو جاهز بكابشن. بيشتغل Offline بالكامل من غير
أي مفتاح API، وبيتحسّن (مش بيتقفّل) بموفري Cloud اختياريين.

## ابدأ من هنا — التثبيت وأول طلب

**الخطوة 1.** افتح Claude Code على جهازك.

**الخطوة 2.** ابعت للـClaude رابط المشروع واطلب منه يجهّزه:

```text
Install and set up:
https://github.com/eslmamin5-creator/video-edit-agent

Use the recommended setup from the repository.
Tell me if any system-level tool is missing before installing it.
```

Claude بيكتشف نظام التشغيل عندك ونسخة Python متوافقة، يبني بيئة تشغيل خاصة
يملكها المشروع نفسه، يثبّت البروفايل الأوفلاين، يتأكد من `ffmpeg`/Node،
ويقولك لما يبقى جاهز — بأي لغة بتكلمه بيها. مفيش مفتاح API مطلوب أو مخزّن
أبدًا.

**الخطوة 3.** لما يقولك جاهز، اطلب اللي عايزه بشكل طبيعي:

بالعربي: `عدل الفيديو ده` · `اعمل فيديو من السكربت ده` · `اجمع المشاهد دي`

بالإنجليزي: "Edit this video" · "Create a video from this script" ·
"Assemble these scenes"

مش محتاج أي أمر CLI في المسار ده. التجربة المفروض تكون حاسسها:

> افتح Claude Code ← ثبّت/افتح video-edit-agent ← اتكلم بشكل طبيعي ← اعمل فيديوهات

مش:

> اقرا التوثيق التقني ← احفظ أوامر CLI ← افهم داخليات الحزمة

## إيه اللي يقدر يعمله؟

قول اللي عندك، والوكيل هيوجّه طلبك — مش لازم تسمّي المسار بنفسك:

| عندك... | تقول | يشتغل |
|---|---|---|
| تصوير خام واحد | "عدل الفيديو ده" | **Editor** |
| سكربت أو فكرة | "اعمل فيديو من السكربت ده" | **Creator** |
| كذا مشهد متصوّر | "اجمع المشاهد دي" | **Assembler** |

لو الطلب فعلاً مش واضح، الوكيل بيسأل سؤال قصير واحد بدل ما يخمّن.

## فيديو خام ← Editor

استخدم Editor لما يكون عندك تسجيل واحد — talking-head، إعلان، مقابلة —
محتاج تنضيف وصقل.

بيفرّغ الصوت، يكتشف ويقص الصمت/التكرار/البدايات الغلط، يبني EDL قابل
للتعديل، يولّد كابشن عربي أو إنجليزي (تشكيل RTL، تظليل كلمة بكلمة)، يخطط
ويحط B-roll، يطبّق موشن جرافيكس (بما فيه وضع خلف الشخص لو القناع متاح)،
يطبّق البراند بتاعك، يعمل فحص جودة، ويرندر الفيديو النهائي.

```bash
videoedit edit my_take.mp4
```

المخرجات بتنزل في `my_take_edit/` جنب الفيديو الأصلي. استخدم `--brand <name>`
لتطبيق براند، و`--offline` لإجبار صفر نداءات شبكة.

## سكربت ← Creator

استخدم Creator لما تبدأ من سكربت مكتوب أو فكرة موصوفة — من غير تصوير لسه.

بيحلل السكربت، يخطط المشاهد، يحلل الإيقاع والبنية، يبني storyboard، يخطط
الأصول اللي محتاجها، يجمّع MasterTimeline، يطبّق معالجة موشن، يرندر، ويعمل
فحص جودة.

```bash
videoedit create my_script.txt
```

بينتج storyboard وخطة أصول وMasterTimeline وفيديو نهائي مرندر، بنفس نمط
الملفات القابلة للمراجعة زي Editor.

## مشاهد ← Assembler

استخدم Assembler لما يكون عندك كذا مشهد متصوّر قبل كده وعايز تجمعهم في فيلم
واحد.

بيكتشف المشاهد، يحافظ على ترتيبك المقصود (أو الترتيب اللي تطلبه)، يبني
rough cut سريع، وبعدين يخطط الاستمرارية ويخلّص بانتقالات حقيقية، دمج صوت،
وتوحيد مستوى الصوت — بإعادة استخدام خطة rough cut بدل ما يبدأ من الأول.

```bash
videoedit assemble my_scenes_dir --rough
videoedit assemble my_scenes_dir --finish
```

`--rough` بيبني معاينة سريعة محافظًا على ترتيب المشاهد. `--finish` بيعيد
استخدام الخطة دي عشان يضيف انتقالات حقيقية ودمج صوت وتوحيد مستوى صوت للفيلم
النهائي. تقدر تستأنف مشروع غير مكتمل بأمان.

## تجربة العربي أولاً

الكلام مع الوكيل بالعربي ميزة في المنتج، مش مجرد قدرة تقنية:

- بتكلم Claude بالعربي وبيرد عليك بعربي طبيعي — مش مترجم من قالب إنجليزي.
- الكابشن يظهر صح: RTL، متشكّل صح، تظليل كلمة بكلمة، وعربي/إنجليزي مختلط في
  نفس السطر.
- اللهجة المصرية والخليجية والسعودية والفصحى بتتحفظ زي ما اتقالت بالظبط.
  الوكيل أبدًا ميحولش اللهجة لفصحى من غير ما تطلب.
- لغة الكلام معايا مالهاش علاقة بترجمة الفيديو نفسه — اللغة اللي بتكلم بيها
  Claude مستقلة عن لغة الفيديو بتاعك.

تحت الغطاء، أهم قاعدة في المشروع ده: **الوكيل بيفرّغ بالظبط اللي اتقال
وأبدًا ميترجمش ولا يعيد صياغة ولا يحوّل اللهجة للعربي المنطوق.** الصوت
الأصلي هو المرجع النهائي. تقنيًا ده معناه تشكيل RTL وإعادة ترتيب bidi
للعرض، ربط حروف عربي صحيح، وحماية لهجة بتمنع التحويل الصامت للفصحى —
تفاصيل ممكن مطوّر يحب يعرفها، مش حاجة لازم تعرفها عشان تستخدم المنتج.

## الموشن، B-roll، وBrand Profiles

**الموشن** — محرك موشن بسيط مدمج بيشتغل Offline دايمًا؛ رندر Remotion
اختياري لموشن أغنى (محتاج Node/npm، من غير مفتاح API)؛ تبديل تلقائي للمحرك
مسجّل دايمًا مش صامت؛ وتقرير حالة الدمج خلف الشخص.

**B-roll** — تخطيط مع بدائل تلقائية للموفرين؛ مسار Offline بالكامل باستخدام
مكتبة محلية؛ وتحسين اختياري بالـCloud (صور/فيديو Gemini) لما تحط المفاتيح.

**Brand Profiles** — ألوان وخطوط وإعدادات كابشن قابلة لإعادة الاستخدام لكل
براند، مخزّنة كفولدرات عادية تحت `brands/<name>/`. مفيش تعديل كود مطلوب
لإضافة واحد:

```bash
videoedit brand init my_brand
videoedit brand validate my_brand
videoedit edit my_take.mp4 --brand my_brand
```

## إيه اللي بيحصل بعد ما تطلب؟

**Editor:**
1. تديله الفيديو.
2. يتأكد إن الأدوات المحلية جاهزة.
3. يفرّغ الكلام.
4. ينضّف الصمت/التكرار/البدايات الغلط.
5. يجهّز الكابشن والمعالجة البصرية.
6. يخطط الموشن/الـB-roll لو مفيد.
7. يرندر الفيديو.
8. يراجع النتيجة ويديك الملفات النهائية.

**Creator:**
1. تديله السكربت أو الفكرة.
2. يفهم البنية.
3. يقسّمها لمشاهد.
4. يبني storyboard وخطة أصول.
5. يطلع بتايم لاين ومعالجة موشن.
6. يرندر ويراجع النتيجة.

**Assembler:**
1. تديله فولدر المشاهد.
2. يكتشف المشاهد.
3. يحافظ على الترتيب أو يتبع ترتيبك.
4. يعمل rough cut.
5. تقدر تراجع وتعدّل.
6. يخلّص الانتقالات والصوت.
7. يسلّمك الفيلم النهائي.

## هتستلم إيه؟

هتستلم الفيديو النهائي، بالإضافة للملفات اللي بتشرح إيه اللي الوكيل غيّره،
عشان تقدر تراجع القرارات أو تكمل المشروع بعدين:

- **الفيديو النهائي** — `final.mp4`.
- **الكابشن والنص الكامل**، لو موجود — `captions.ass`،
  `transcript_unified.json`.
- **قرارات مونتاج قابلة للتعديل** — `edl.json` (قايمة قرارات المونتاج)
  وMasterTimeline لـCreator، الاتنين قابلين لإعادة الرندر من غير إعادة كل
  الخط.
- **تقارير شفافية** — `project.md` (ليه الوكيل اتخذ كل قرار) وملفات خطط
  الموشن/B-roll/الجودة.

كل مرحلة ملف عادي، أبدًا مش حالة مخفية — تقدر تفتح أي واحد منهم مباشرة.

## Offline مقابل Cloud

**تقدر تستخدم المسارات الأساسية — Editor وCreator وAssembler — من غير أي
مفتاح API.**

| القدرة | يشتغل من غير مفاتيح API | إيه اللي بيضيفه الـCloud |
|---|---|---|
| تفريغ الكلام | آه — Faster-Whisper محلي | تفريغ Gemini / ElevenLabs (اختياري، محتاج مفتاح API) |
| كابشن (تشكيل RTL، تظليل karaoke) | آه، محلي بالكامل | — |
| مونتاج (صمت/تكرار/بدايات غلط، EDL) | آه، محلي بالكامل | — |
| موشن جرافيكس | آه — محرك بسيط مدمج | Remotion (محتاج Node/npm، من غير مفتاح API) لموشن أغنى |
| B-roll | آه — مكتبة/تخطيط محلي | توليد Gemini للصور/الفيديو لـB-roll بالذكاء الاصطناعي |
| فحص جودة بصري | آه — فحوصات محلية أساسية | Gemini Vision لفحص أغنى |
| Brand Profiles، EDL، رندر، rough/finish الـAssembler | آه، محلي بالكامل | — |

`GEMINI_API_KEY` و`ELEVENLABS_API_KEY` بيتقروا بس من متغيرات البيئة، أبدًا
من ملف إعدادات، وأبدًا مبيتطبعوش أو يتسجلوا في أي أمر — حتى `videoedit
doctor`.

الرندر — مش فيديو نهائي لازم تعيده من الأول — الوكيل بيقدر يطبّق التعديل

بالعربي: `شيل الجملة دي` · `خلي الفيديو أسرع` · `الكابشن كبير زيادة` ·

## حل المشاكل

**الكابشن مكتوب غلط.**
قول لـClaude الكلمة الصحيحة، واطلب منه تحديث الكابشن.

**الفيديو طويل.**
اطلب منه يقصّر الفيديو أو يشيل جزء معين.

**عايز Offline فقط.**
قله: اشتغل Offline فقط.

**أداة ناقصة.**
Claude هيقولك بالظبط أي أداة نظام ناقصة (زي `ffmpeg`) وهيسألك قبل ما يثبّت
أو يغيّر أي حاجة على جهازك — مايثبتش برامج على مستوى النظام من غير ما
يسألك.

**الشغل وقف.**
اطلب من Claude يفحص حالة المشروع ويكمل من المشروع المحفوظ. كل مرحلة ملف
عادي يقدر يقرأه تاني، فبيقدر يكمّل المسارات المدعومة من غير ما يبدأ من
الأول — لكن مش كل توقف مضمون يكمل بسلاسة؛ اسأله الأول يتأكد.

لفحص جاهزية مباشر ومرتبط بجهازك في أي وقت:

```bash
videoedit doctor
```

بيطبع مصفوفة القدرات الكاملة (ffmpeg، Node، الموفرين، المحركات) بالإضافة
لملخص آخر تشغيل لـ`videoedit setup`. شغّل `videoedit setup --check` لفحص
جاهزية بدون تغيير، أو `videoedit setup --repair` لإعادة بناء بيئة التشغيل
الخاصة من الصفر من غير ما يغيّر أي حاجة برّه `.runtime/`.

## القيود المعروفة

- ASR عربي على صوت حقيقي منطوق ورندر موشن Remotion لسه مش متحقق منهم
  بتشغيل قبول حقيقي في هذه البيئة — شوف جدول حالة القدرات في الـREADME
  للتفاصيل الكاملة.
- تعديلات J-Cut/L-Cut مفهومية بس، مش متطبقة.
- HyperFrames مش محرك موشن حقيقي قابل للتثبيت؛ الموجّه دايمًا بيرجع لمحرك
  شغال ويسجّل ده — أبدًا مش استبدال صامت.
- استئناف العمل بعد التوقف مدعوم لتدفق rough → finish بتاع Assembler؛
  باقي المسارات لسه مش بتضمن استئناف سلس من كل نقطة توقف.

## ملحق متقدّم / تقني

### التثبيت مع Claude Code (التفاصيل الكاملة)

1. اعمل clone أو ثبّت المشروع في فولدر الـskills بتاع Claude Code.
2. افتح (أو أعد فتح) Claude Code.
3. قول: **"جهّز video-edit-agent وتأكد إنه شغال."**

Claude هيجهّز كل حاجة لوحده: يكتشف نظام التشغيل عندك ونسخة Python متوافقة
(يفضّل 3.11)، يبني بيئة تشغيل خاصة يملكها المشروع (`.runtime/venv` — مش
Python بتاع النظام أبدًا)، يثبّت البروفايل الأوفلاين، يتأكد من `ffmpeg`/
`ffprobe` وNode/npm، ويقولك النتيجة بشكل بسيط وبأي لغة بتكلمه بيها. مايثبتش
برامج على مستوى النظام من غير ما يسألك — لو `ffmpeg` ناقص، هيديك الأمر
بالظبط لنظامك وينتظرك تشغّله.

### التثبيت من المصدر (للمستخدمين المتقدمين)

```bash
git clone https://github.com/eslmamin5-creator/video-edit-agent
cd video-edit-agent
python3 -m pip install -e .          # base CLI only
videoedit setup --profile full-local # builds .runtime/venv, installs the offline profile
```

`videoedit setup` بيدعم `--profile local|subject|motion|core` لتثبيت أضيق،
`--check` لفحص جاهزية بدون تغيير، و`--repair` لإعادة بناء بيئة التشغيل
الخاصة من الصفر.

### مرجع أوامر CLI

| الأمر | الوظيفة |
|---|---|
| `videoedit edit <video>` | الخط الكامل: تفريغ ← قص ← كابشن ← B-roll ← موشن ← رندر ← QA |
| `videoedit create <script>` | سكربت ← storyboard ← خطة أصول ← موشن ← رندر ← QA |
| `videoedit assemble <scenes_dir> --rough` | rough cut سريع من فولدر مشاهد جاهزة |
| `videoedit assemble <scenes_dir> --finish` | إكمال بانتقالات حقيقية + توحيد مستوى صوت |
| `videoedit doctor` | طباعة مصفوفة القدرات |
| `videoedit providers` | عرض موفري التفريغ/الموشن وتوفرهم |
| `videoedit setup [--profile ...] [--check] [--repair]` | تجهيز بيئة التشغيل، فحص الجاهزية |
| `videoedit config show / set` | فحص أو تعديل الإعدادات الطبقية (أبدًا مش الأسرار) |
| `videoedit brand init / validate` | إنشاء أو فحص Brand Profile |
| `videoedit project inspect <dir>` | طباعة ذاكرة `project.md` بتاعة المشروع |

### ملفات المشروع (القايمة الكاملة)

`project.md`، `transcript_unified.json`، `edl.json`، `captions.ass`، ملف
خطة الموشن، ملف خطة B-roll، ملف خطة QA، و`final.mp4`.
