# video-edit-agent

**video-edit-agent هو وكيل مونتاج وإنتاج فيديو داخل Claude Code.** كلّم الوكيل
بلغتك العادية — عربي أو إنجليزي:

- عندك فيديو خام؟ يعدّله.
- عندك سكربت؟ يحوّله لفيديو.
- عندك مشاهد جاهزة؟ يجمعها ويخرج فيديو نهائي.

يشتغل Offline بالكامل لو عايز، ويتحسّن أكتر لو ضفت مفاتيح Cloud. أمر الـCLI:
`videoedit`.

## ابدأ من هنا

**الخطوة 1.** افتح Claude Code على جهازك.

**الخطوة 2.** ابعت للـClaude رابط المشروع واطلب منه يجهّزه:

```text
Install and set up:
https://github.com/eslmamin5-creator/video-edit-agent

Use the recommended setup from the repository.
Tell me if any system-level tool is missing before installing it.
```

Claude هيجهّز كل حاجة لوحده: يكتشف نظام التشغيل عندك ونسخة Python متوافقة،
يبني بيئة تشغيل خاصة يملكها المشروع نفسه، يثبّت البروفايل الأوفلاين، يتأكد من
`ffmpeg`/Node، ويقولك النتيجة بأي لغة بتكلمه بيها. مفيش مفتاح API مطلوب أو
مخزّن أبدًا. للتفاصيل الكاملة شوف [التثبيت مع Claude Code](#التثبيت-مع-claude-code)
تحت.

**الخطوة 3.** لما يقولك جاهز، اطلب اللي عايزه بشكل طبيعي — من غير أي أمر CLI
في المسار ده:

بالعربي:
- `عدل الفيديو ده`
- `اعمل فيديو من السكربت ده`
- `اجمع المشاهد دي`

بالإنجليزي:
- `Edit this video`
- `Create a video from this script`
- `Assemble these scenes`

## محتاج أي مسار؟

مش لازم تختار بنفسك — قول اللي عندك، والوكيل هيوجّه طلبك للمسار الصح:

| عندك... | تقول (مثال) | يشتغل |
|---|---|---|
| تصوير خام واحد (talking-head، إعلان، مقابلة) | "عدل الفيديو ده" / "Edit this video" | **Editor** |
| سكربت أو فكرة، من غير تصوير لسه | "اعمل فيديو من السكربت ده" / "Create a video from this script" | **Creator** |
| كذا مشهد متصوّر قبل كده | "اجمع المشاهد دي" / "Assemble these scenes" | **Assembler** |

لو الطلب فعلاً مش واضح، الوكيل بيسأل سؤال قصير واحد للتوضيح بدل ما يخمّن.

## إيه اللي بيحصل بعد ما أطلب؟

**Editor** (فيديو خام):
1. تديله الفيديو.
2. يتأكد إن الأدوات المحلية جاهزة.
3. يفرّغ الكلام (transcribe).
4. ينضّف الصمت/التكرار/البدايات الغلط.
5. يجهّز الكابشن والمعالجة البصرية.
6. يخطط الموشن/الـB-roll لو مفيد.
7. يرندر الفيديو.
8. يراجع النتيجة ويديك الملفات النهائية.

**Creator** (سكربت):
1. تديله السكربت أو الفكرة.
2. يفهم البنية.
3. يقسّمها لمشاهد.
4. يبني storyboard وخطة أصول.
5. يطلع بتايم لاين ومعالجة موشن.
6. يرندر ويراجع النتيجة.

**Assembler** (مشاهد):
1. تديله فولدر المشاهد.
2. يكتشف المشاهد.
3. يحافظ على الترتيب أو يتبع ترتيبك.
4. يعمل rough cut.
5. تقدر تراجع/تعدّل.
6. يخلّص الانتقالات/الصوت.
7. يسلّمك الفيلم النهائي.

## هستلم إيه؟

هتستلم الفيديو النهائي، بالإضافة للملفات اللي بتشرح إيه اللي الوكيل غيّره،
عشان تقدر تراجع القرارات أو تكمل المشروع بعدين: الكابشن/النص الكامل لو موجود،
وقرارات مونتاج قابلة للتعديل وإعادة الرندر. شوف [المخرجات وملفات المشروع](#المخرجات-وملفات-المشروع)
لتفاصيل الملفات بالظبط.

## Editor / Creator / Assembler

### Editor — تصوير خام واحد، فيديو جاهز
لو عندك تسجيل talking-head أو إعلان متصوّر خلاص. بيعمل: تفريغ الكلام، تنضيف
الصمت/التكرار/البدايات الغلط، كابشن (تشكيل عربي RTL، تظليل الكلمة بالكلمة)،
موشن جرافيكس، تخطيط B-roll، وضع جرافيك خلف الشخص لو متاح، ستايل البراند، فحص
جودة، ورندر نهائي. تشغيل: `videoedit edit <video>`.

### Creator — سكربت أو فكرة، فيديو جاهز
لو معندكش تصوير لسه، بس فكرة أو سكربت مكتوب. بيعمل: تحليل السكربت، تخطيط
مشاهد، تحليل، storyboard، خطة أصول، MasterTimeline، معالجة موشن، رندر، وفحص
جودة. تشغيل: `videoedit create <script>`.

### Assembler — مشاهد كتير جاهزة، فيلم واحد
لو عندك فولدر مشاهد متصوّرة قبل كده. بيعمل: اكتشاف المشاهد، الحفاظ على
الترتيب، rough cut سريع، تخطيط استمرارية، انتقالات حقيقية، دمج صوت، توحيد
مستوى الصوت، والإكمال/الاستئناف. تشغيل: `videoedit assemble <scenes_dir> --rough`
ثم `--finish`.

## العربي أولاً، مع الحفاظ على اللهجة

الكلام مع الوكيل بالعربي ميزة في المنتج، مش مجرد دعم تقني لـRTL:

- بتكلم Claude بالعربي وبيرد عليك بعربي طبيعي — مش مترجم من قالب إنجليزي.
- الكابشن يظهر صح: RTL، متشكّل صح، تظليل كلمة بكلمة (karaoke)، وعربي/إنجليزي
  مختلط في نفس السطر.
- اللهجة المصرية والخليجية والسعودية والفصحى بتتحفظ زي ما اتقالت بالظبط —
  الوكيل أبدًا ميحولش اللهجة لفصحى من غير ما تطلب.
- **لغة الكلام معايا مالهاش علاقة بترجمة الفيديو نفسه.** لو كلمت Claude
  بالعربي عن فيديو بالإنجليزي، النص والكابشن بتوع الفيديو فاضلين إنجليزي —
  وشرح الوكيل ليك بيفضل عربي. في الاتجاهين، الصوت الأصلي مايتغيّرش بسبب لغة
  السؤال.

التفاصيل التقنية (تشكيل RTL، ربط الحروف، منطق حماية اللهجة) موجودة في
[دليل المستخدم](docs/USER_GUIDE.ar.md) لمين عايز يعرف أكتر.

## حل المشاكل بكلام بسيط

**"الكابشن مكتوب غلط"**
قول لـClaude الكلمة الصحيحة، واطلب منه تحديث الكابشن.

**"الفيديو طويل"**
اطلب منه يقصّر الفيديو أو يشيل جزء معين.

**"عايز Offline فقط"**
قله: اشتغل Offline فقط.

**"أداة ناقصة"**
Claude هيقولك بالظبط أي أداة نظام ناقصة (زي `ffmpeg`) وهيسألك قبل ما يثبّت
أو يغيّر أي حاجة على جهازك — مايثبتش برامج على مستوى النظام من غير ما يسألك.

**"الشغل وقف"**
اطلب من Claude يفحص حالة المشروع ويكمل من المشروع المحفوظ. كل مرحلة ملف عادي
يقدر يقرأه تاني، فبيقدر يكمّل المسارات المدعومة من غير ما يبدأ من الأول — لكن
مش كل توقف مضمون يكمل بسلاسة؛ اسأله الأول يتأكد.

## أهم الميزات

- **ذكاء المونتاج** — مونتاج مبني على النص الكامل، تعامل مع الصمت/التكرار/
  البدايات الغلط، EDL قابل للمراجعة وإعادة الرندر (غيّر قرار وأعِد الرندر —
  من غير ما تعيد كل الخط بالكامل)، وذاكرة `project.md` دائمة بتشرح إيه اللي
  الوكيل قرره وليه.
- **العربي** — كابشن RTL، تشكيل عربي، تظليل كلمة بكلمة، حفاظ على المصري/
  الخليجي/السعودي/الفصحى، نص عربي/إنجليزي مختلط، وأبدًا مفيش تحويل لهجة مخفي.
- **الموشن** — محرك موشن بسيط مدمج بيشتغل Offline دايمًا، رندر Remotion
  اختياري، تبديل تلقائي للمحرك عند الحاجة، تقرير حالة الوضع خلف الشخص، وستايل
  مرتبط بالبراند.
- **B-roll** — تخطيط مع بدائل تلقائية، مسار Offline بالكامل، وتحسين اختياري
  بالـCloud (صور/فيديو Gemini) لما تحط المفاتيح.
- **خط Creator** — سكربت ← تحليل ← مشاهد ← storyboard ← خطة أصول ← تايم لاين
  ← رندر.
- **خط Assembler** — rough cut ← إكمال، مع الحفاظ على ترتيب المشاهد، تخطيط
  استمرارية، انتقالات حقيقية، دمج صوت، وتوحيد مستوى الصوت.
- **Brand Profiles** — ألوان وخطوط وإعدادات كابشن قابلة لإعادة الاستخدام لكل
  براند، من غير أي تعديل في الكود.
- **قابلية للمراجعة** — كل مرحلة ملف عادي تقدر تفتحه: `project.md`، النص
  الكامل، EDL، MasterTimeline، خطط الموشن/B-roll/الجودة، والفيديو النهائي.

## Offline مقابل Cloud

**تقدر تستخدم المسارات الأساسية — Editor وCreator وAssembler — من غير أي
مفتاح API.** موفرو الـCloud بس بيضيفوا تحسينات اختيارية فوق كده:

| | يشتغل من غير مفاتيح API | إيه اللي بيضيفه لو اتظبط |
|---|---|---|
| تفريغ الكلام | آه — Faster-Whisper محلي | `GEMINI_API_KEY` / `ELEVENLABS_API_KEY` بيفتحوا تفريغ Cloud |
| كابشن، تشكيل RTL، تظليل karaoke | آه، محلي بالكامل | — |
| مونتاج (صمت/تكرار/بدايات غلط، EDL) | آه، محلي بالكامل | — |
| موشن جرافيكس | آه — محرك بسيط مدمج | Remotion (محتاج Node/npm، من غير مفتاح API) لموشن أغنى |
| B-roll | مكتبة/تخطيط محلي احتياطي | توليد Gemini للصور/الفيديو لـB-roll بالذكاء الاصطناعي |
| فحص جودة بصري | فحوصات محلية أساسية | Gemini Vision لفحص أغنى |
| Brand Profiles، EDL، رندر، rough/finish الـAssembler | آه، محلي بالكامل | — |

مفيش مفتاح API مطلوب أبدًا عشان الخط الأساسي يكمل. المفاتيح بتتقرأ بس من
متغيرات البيئة `GEMINI_API_KEY` / `ELEVENLABS_API_KEY` — أبدًا مبتتكتبش في
ملف إعدادات، ولا بتتسجّل، ولا بتتطبع في أي أمر.

## التثبيت مع Claude Code

1. اعمل clone أو ثبّت المشروع في فولدر الـskills بتاع Claude Code.
2. افتح (أو أعد فتح) Claude Code.
3. قول: **"جهّز video-edit-agent وتأكد إنه شغال."**

Claude هيجهّز كل حاجة لوحده: يكتشف نظام التشغيل عندك ونسخة Python متوافقة
(يفضّل 3.11)، يبني بيئة تشغيل خاصة يملكها المشروع (`.runtime/venv` — مش
Python بتاع النظام أبدًا)، يثبّت البروفايل الأوفلاين، يتأكد من `ffmpeg`/
`ffprobe` وNode/npm، ويقولك النتيجة بشكل بسيط وبأي لغة بتكلمه بيها. مايثبتش
برامج على مستوى النظام من غير ما يسألك — لو `ffmpeg` ناقص، هيديك الأمر
بالظبط لنظامك وينتظرك تشغّله. مفيش مفتاح API مطلوب أو مخزّن أبدًا.

مش لازم تفهم بيئات Python الافتراضية ولا pip extras ولا توجيه الموفرين عشان
تستخدم المسار ده.

## استخدام CLI التقني

### التثبيت من المصدر (للمستخدمين المتقدمين)

```bash
git clone https://github.com/eslmamin5-creator/video-edit-agent
cd video-edit-agent
python3 -m pip install -e .          # base CLI only
videoedit setup --profile full-local # builds .runtime/venv, installs the offline profile
```

على Windows (PowerShell)، من غير WSL:

```powershell
git clone https://github.com/eslmamin5-creator/video-edit-agent
cd video-edit-agent
py -3.11 -m pip install -e .
videoedit setup --profile full-local
```

`videoedit setup` بيدعم:

| الأمر | بيعمل إيه |
|---|---|
| `videoedit setup` | تجهيز كامل بالبروفايل الموصى بيه `full-local` (أوفلاين). |
| `videoedit setup --profile local\|subject\|motion\|core` | تجهيز ببروفايل أضيق. |
| `videoedit setup --check` | فحص فقط — يقول الحالة من غير أي تغيير. |
| `videoedit setup --repair` | يعيد بناء بيئة التشغيل الخاصة من الصفر، حتى لو شكلها سليم؛ أبدًا مبيغيّرش أي حاجة برّه `.runtime/`. |

إعادة تشغيل `videoedit setup` آمنة دايمًا — بتعيد استخدام بيئة سليمة بدل ما
تعيد التثبيت.

التثبيت من PyPI (`pip install video-edit-agent`) لسه شغال للـCLI الأساسي
وأي extra منفصل (`pip install "video-edit-agent[local]"`)، لكن التثبيت من
GitHub/المصدر مع `videoedit setup` هو المسار المدعوم بالكامل.

**أنظمة التشغيل المدعومة:** Windows (PowerShell، من غير WSL)، macOS، Linux.
**Python:** 3.10+ مطلوب؛ 3.11 مفضّل وبيتم اختياره تلقائيًا لو متاح.
**ffmpeg/ffprobe:** مطلوب لأي رندر؛ `videoedit setup`/`doctor` بيكتشفوه
ويديك إرشادات التثبيت بالظبط لو ناقص — أبدًا مبيتثبتش لوحده تلقائيًا.
**Node/npm:** اختياري — مطلوب بس لمحرك موشن Remotion؛ المحرك البسيط المدمج
بيشتغل Offline بالكامل من غيره.
**مفاتيح API:** اختيارية دايمًا. صفر مفاتيح إعداد مدعوم بالكامل وشغال 100%.

شغّل `videoedit doctor` في أي وقت عشان تشوف مصفوفة القدرات الكاملة وملخص آخر
تشغيل لـ`videoedit setup`.

### بداية سريعة

```bash
videoedit setup           # one-time bootstrap: private runtime + offline profile + capability check
videoedit doctor           # see the full capability matrix
videoedit edit my_take.mp4
```

المخرجات بتنزل في `my_take_edit/` (فولدر `edit/` جنب الفيديو الأصلي):
`final.mp4`، `transcript_unified.json`، `edl.json`، `captions.ass`،
`project.md`، وملفات خطط QA/B-roll/الموشن.

### الأوامر

| الأمر | الغرض |
|---|---|
| `videoedit edit <video>` | الخط الكامل: تفريغ ← قص ← كابشن ← B-roll ← موشن ← رندر ← QA |
| `videoedit create <script>` | سكربت ← storyboard ← خطة أصول ← موشن ← رندر ← QA |
| `videoedit assemble <scenes_dir> --rough` | rough cut سريع من فولدر مشاهد جاهزة |
| `videoedit assemble <scenes_dir> --finish` | إكمال الفيلم: انتقالات حقيقية + توحيد صوت بين المشاهد، بإعادة استخدام خطة rough cut |
| `videoedit doctor` | طباعة مصفوفة القدرات (ffmpeg، Node، الموفرين، المحركات) |
| `videoedit providers` | عرض موفري التفريغ/الموشن وتوفرهم |
| `videoedit setup [--profile ...] [--check] [--repair]` | تجهيز بيئة التشغيل الخاصة وفحص جاهزية البيئة |
| `videoedit config show / set` | فحص أو تعديل الإعدادات الطبقية (أبدًا مش الأسرار) |
| `videoedit brand init / validate` | إنشاء أو فحص Brand Profile |
| `videoedit project inspect <dir>` | طباعة ذاكرة `project.md` بتاعة المشروع |

## حالة القدرات (اعتبارًا من v0.2.2)

حالة صادقة لكل قدرة، بستة فئات: `VERIFIED LOCALLY` (تشغيل قبول حقيقي غير
وهمي نجح محليًا)، `VERIFIED WITH CLOUD` (نداء API حي حقيقي نجح)، `OPTIONAL`
(مش مطلوب للخط الأساسي)، `FALLBACK AVAILABLE` (بيرجع لبديل شغال بسلاسة)،
`NOT VERIFIED` (الكود موجود بس من غير دليل قبول حقيقي)، `REQUIRES API KEY`
(محتاج تحط مفتاح). شغّل `videoedit doctor` عشان تشوف نفس المصفوفة دي مباشرة
على جهازك.

## المخرجات وملفات المشروع

كل مرحلة في أي خط ملف عادي قابل للمراجعة جنب الفيديو/المشروع — مفيش حاجة
مخفية في حالة غامضة:

`project.md` (ذاكرة قابلة للقراءة للقرارات وليه)، `transcript_unified.json`،
`edl.json`، `captions.ass`، ملفات خطط الموشن/B-roll/QA، و`final.mp4`.

## الأسرار

`GEMINI_API_KEY` و`ELEVENLABS_API_KEY` بيتقروا بس من متغيرات البيئة. أبدًا
مبيتكتبوش في ملف إعدادات، ولا بيتسجلوا، ولا بيتطبعوا في أي أمر — حتى `doctor`.

## Brand Profiles

البراندات عبارة عن فولدرات عادية تحت `brands/<name>/` (ألوان، خطوط، قايمة
تجنّب، محرك موشن مفضّل، إعداد كابشن). مفيش تعديل كود مطلوب لإضافة واحد:

```bash
videoedit brand init my_brand
videoedit brand validate my_brand
videoedit edit my_take.mp4 --brand my_brand
```

## القيود المعروفة

- ASR عربي على صوت حقيقي منطوق ورندر موشن Remotion لسه مش متحقق منهم بتشغيل
  قبول حقيقي في هذه البيئة (شوف جدول حالة القدرات فوق).
- تعديلات J-Cut/L-Cut مفهومية بس، مش متطبقة.
- HyperFrames مش محرك حقيقي قابل للتثبيت؛ الموجّه دايمًا بيرجع لمحرك شغال
  ويسجّل ده.
- استئناف العمل بعد التوقف مدعوم لتدفق rough → finish بتاع Assembler؛ باقي
  المسارات لسه مش بتضمن استئناف سلس من كل نقطة توقف.
