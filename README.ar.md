# video-edit-agent

وكيل مونتاج فيديو بالذكاء الاصطناعي، يضع اللغة العربية أولاً، ولا يرتبط بمزوّد
نموذج واحد. يحوّل تسجيلًا خامًا (حديث مباشر أمام الكاميرا أو إعلانًا) إلى فيديو
نهائي مقصوص، مع ترجمات، ورسوم متحركة — يعمل بالكامل دون اتصال إن أردت، أو
يُعزَّز بخدمات سحابية إذا زوّدته بمفاتيح API.

أمر سطر الأوامر: `videoedit`. للنسخة الإنجليزية انظر [README.md](README.md).

## الفلسفة

- **العربية أولًا، مع الحفاظ على اللهجة.** يقوم الوكيل بتفريغ ما قيل بالضبط —
  مصرية، خليجية، سعودية، فصحى، أو مزيج عربي/إنجليزي — ولا يعيد كتابة اللهجة أو
  "تصحيحها" أو تحويلها إلى لهجة أخرى أبدًا. الصوت المصدر هو المرجع النهائي.
  انظر `language/dialect_guard.py`.
- **يعمل بدون أي مفتاح API.** كل ميزة تعتمد على السحابة (تفريغ ورؤية Gemini،
  ElevenLabs، توليد صور/فيديو Veo) لها بديل تلقائي يعمل محليًا. بدون أي مفاتيح،
  يستمر أمر `videoedit edit` في التفريغ محليًا (Faster-Whisper)، وبناء خطة
  المونتاج، والترجمات، والتركيب، والتصدير — فقط دون التحسينات السحابية.
- **معزَّز بالسحابة، وليس معتمدًا عليها.** عيّن `GEMINI_API_KEY` و/أو
  `ELEVENLABS_API_KEY` كمتغيرات بيئة (أبدًا في ملف إعدادات) لفتح تفريغ أفضل،
  ومواد بصرية إضافية مولَّدة، وفحص جودة بصري.
- **مرن وقابل للفحص.** كل مرحلة (النص، خطة المونتاج، الترجمات، خطة المواد
  الإضافية، خطة الرسوم المتحركة، تقرير الجودة) هي ملف JSON أو نصي واضح داخل
  `<video>/edit/`، ويحتفظ `project.md` بذاكرة قابلة للقراءة توضح قرارات الوكيل
  وأسبابها.

## التثبيت

```bash
pip install video-edit-agent
```

أو لدعم التفريغ المحلي (بدون اتصال):

```bash
pip install "video-edit-agent[local]"
```

يجب توفر `ffmpeg`/`ffprobe` ضمن `PATH`. بعد التثبيت شغّل `videoedit doctor`
لمعرفة ما هو متاح بالضبط على جهازك.

## بداية سريعة

```bash
videoedit setup          # فحص أولي للبيئة + تثبيت اختياري لـ Whisper المحلي
videoedit doctor         # عرض جدول القدرات الكامل
videoedit edit my_take.mp4
```

تجد المخرجات داخل مجلد `edit/` بجانب الفيديو المصدر: `final.mp4`،
`transcript_unified.json`، `edl.json`، `captions.ass`، `project.md`، وملفات
خطط الجودة/المواد الإضافية/الرسوم المتحركة بصيغة JSON.

## الأوامر الأساسية

| الأمر | الوظيفة |
|---|---|
| `videoedit edit <video>` | تشغيل خط الأنابيب الكامل: تفريغ -> قص -> ترجمة -> مواد إضافية -> رسوم متحركة -> تصدير -> جودة |
| `videoedit doctor` | عرض جدول القدرات (ffmpeg، Node، المزوّدون، المحركات) |
| `videoedit providers` | عرض مزوّدي التفريغ والرسوم المتحركة وتوفرهم |
| `videoedit setup` | معالج إعداد تفاعلي للمرة الأولى |
| `videoedit config show / set` | عرض أو تعديل الإعدادات المتراكبة (بدون أي أسرار) |
| `videoedit brand init / validate` | إنشاء أو التحقق من ملف هوية علامة تجارية |
| `videoedit project inspect <dir>` | عرض ذاكرة `project.md` لمشروع ما |

## الأسرار

`GEMINI_API_KEY` و `ELEVENLABS_API_KEY` تُقرأ فقط من متغيرات البيئة. لا تُكتب
أبدًا في ملف إعدادات، ولا تُسجَّل، ولا تُطبع أبدًا من أي أمر، بما في ذلك
`doctor`.

## ملفات الهوية التجارية (Brand Profiles)

تعيش الهويات التجارية كمجلدات عادية تحت `brands/<name>/` (الألوان، الخطوط،
قائمة الكلمات الممنوعة، محرك الرسوم المتحركة المفضل، نمط الترجمات). لا حاجة
لتعديل الشيفرة المصدرية لإضافة واحدة:

```bash
videoedit brand init my_brand
videoedit brand validate my_brand
videoedit edit my_take.mp4 --brand my_brand
```
