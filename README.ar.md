# video-edit-agent

وكيل مونتاج فيديو بالذكاء الاصطناعي، يضع اللغة العربية أولاً، ولا يرتبط بمزوّد
نموذج واحد. يحوّل تسجيلًا خامًا (حديث مباشر أمام الكاميرا أو إعلانًا) إلى فيديو
نهائي مقصوص، مع ترجمات، ورسوم متحركة — يعمل بالكامل دون اتصال إن أردت، أو
يُعزَّز بخدمات سحابية إذا زوّدته بمفاتيح API.

أمر سطر الأوامر: `videoedit`. للنسخة الإنجليزية انظر [README.md](README.md).

ثلاثة وكلاء يغطون ثلاثة سير عمل، جميعها تعمل دون اتصال:

- **Editor** (`videoedit edit`) — يحوّل تسجيلًا خامًا واحدًا إلى فيديو نهائي مقصوص ومترجم.
- **Creator** (`videoedit create`) — يحوّل نصًا (سكريبت) إلى لوحة قصة كاملة وخطة مواد وفيديو نهائي مُصدَّر.
- **Assembler** (`videoedit assemble`) — يحوّل مجلدًا من مشاهد مصوَّرة مسبقًا إلى قصة أولية (`--rough`) ثم فيلم نهائي (`--finish`) مع انتقالات حقيقية وتطبيع لطبقة الصوت بين المشاهد.

## الفلسفة

- **العربية أولًا، مع الحفاظ على اللهجة.** يقوم الوكيل بتفريغ ما قيل بالضبط —
  مصرية، خليجية، سعودية، فصحى، أو مزيج عربي/إنجليزي — ولا يعيد كتابة اللهجة أو
  "تصحيحها" أو تحويلها إلى لهجة أخرى أبدًا. الصوت المصدر هو المرجع النهائي.
  انظر `language/dialect_guard.py`.
- **يعمل بدون أي مفتاح API.** كل ميزة تعتمد على السحابة (تفريغ ورؤية Gemini،
  ElevenLabs، توليد صور/فيديو Veo) لها بديل تلقائي يعمل محليًا. بدون أي مفاتيح،
  يستمر أمر `videoedit edit` في التفريغ محليًا (Faster-Whisper)، وبناء خطة
  المونتاج، والترجمات، والتركيب، والتصدير — فقط دون التحسينات السحابية.
- **معزَّز بالسحابة، وليس معتمدًا عليها.** عيّن `GEMINI_API_KEY` و/أو
  `ELEVENLABS_API_KEY` كمتغيرات بيئة (أبدًا في ملف إعدادات) لفتح تفريغ أفضل،
  ومواد بصرية إضافية مولَّدة، وفحص جودة بصري.
- **مرن وقابل للفحص.** كل مرحلة (النص، خطة المونتاج، الترجمات، خطة المواد
  الإضافية، خطة الرسوم المتحركة، تقرير الجودة) هي ملف JSON أو نصي واضح داخل
  `<video>/edit/`، ويحتفظ `project.md` بذاكرة قابلة للقراءة توضح قرارات الوكيل
  وأسبابها.

## التثبيت

```bash
pip install video-edit-agent
```

أو لدعم التفريغ المحلي (بدون اتصال):

```bash
pip install "video-edit-agent[local]"
```

يجب توفر `ffmpeg`/`ffprobe` ضمن `PATH`. بعد التثبيت شغّل `videoedit doctor`
لمعرفة ما هو متاح بالضبط على جهازك.

## بداية سريعة

```bash
videoedit setup          # فحص أولي للبيئة + تثبيت اختياري لـ Whisper المحلي
videoedit doctor         # عرض جدول القدرات الكامل
videoedit edit my_take.mp4
```

تجد المخرجات داخل مجلد `edit/` بجانب الفيديو المصدر: `final.mp4`،
`transcript_unified.json`، `edl.json`، `captions.ass`، `project.md`، وملفات
خطط الجودة/المواد الإضافية/الرسوم المتحركة بصيغة JSON.

## الأوامر الأساسية

| الأمر | الوظيفة |
|---|---|
| `videoedit edit <video>` | تشغيل خط الأنابيب الكامل: تفريغ -> قص -> ترجمة -> مواد إضافية -> رسوم متحركة -> تصدير -> جودة |
| `videoedit create <script>` | تحويل نص إلى لوحة قصة -> خطة مواد -> رسوم متحركة -> تصدير -> جودة |
| `videoedit assemble <scenes_dir> --rough` | بناء قصة أولية سريعة من مجلد مشاهد مصوَّرة مسبقًا |
| `videoedit assemble <scenes_dir> --finish` | إتمام الفيلم: انتقالات حقيقية + تطبيع الصوت بين المشاهد، مع إعادة استخدام خطة القصة الأولية |
| `videoedit doctor` | عرض جدول القدرات (ffmpeg، Node، المزوّدون، المحركات) |
| `videoedit providers` | عرض مزوّدي التفريغ والرسوم المتحركة وتوفرهم |
| `videoedit setup` | معالج إعداد تفاعلي للمرة الأولى |
| `videoedit config show / set` | عرض أو تعديل الإعدادات المتراكبة (بدون أي أسرار) |
| `videoedit brand init / validate` | إنشاء أو التحقق من ملف هوية علامة تجارية |
| `videoedit project inspect <dir>` | عرض ذاكرة `project.md` لمشروع ما |

## حالة القدرات (اعتبارًا من الإصدار v0.2.0)

حالة صادقة لكل قدرة، باستخدام ست فئات:
`VERIFIED LOCALLY` (اجتاز اختبار قبول محلي حقيقي وغير وهمي)،
`VERIFIED WITH CLOUD` (نجح استدعاء API حقيقي مباشر)، `OPTIONAL` (غير مطلوب
لخط الأنابيب الأساسي)، `FALLBACK AVAILABLE` (يتراجع بسلاسة إلى بديل يعمل)،
`NOT VERIFIED` (الشيفرة موجودة لكن لا يوجد دليل قبول حقيقي)، `REQUIRES API KEY`
(محظور حتى تضبط مفتاحًا). شغّل `videoedit doctor` لعرض حي لنفس الجدول خاص
بجهازك.

| القدرة | الحالة | ملاحظات |
|---|---|---|
| التفريغ المحلي (Faster-Whisper) | VERIFIED LOCALLY | خط أنابيب `videoedit edit` الكامل بدون اتصال يعمل من البداية للنهاية بدون أي مفتاح API. |
| تفريغ Gemini | REQUIRES API KEY | المهايئ مُنفَّذ ومُختبَر بوحدات اختبار؛ يُتخطّى الاستدعاء المباشر تلقائيًا ما لم يُضبط `GEMINI_API_KEY`. لم يُختبر مقابل الـ API الحقيقي في هذه البيئة. |
| تفريغ ElevenLabs | REQUIRES API KEY / OPTIONAL | غير مطلوب أبدًا لإتمام خط الأنابيب؛ يُتخطّى الاستدعاء المباشر تلقائيًا ما لم يُضبط `ELEVENLABS_API_KEY`. |
| الترجمات العربية (اتجاه RTL، التشكيل/الربط، تظليل الكاراوكي، مزيج عربي/إنجليزي، خطوط الهوية التجارية) | VERIFIED LOCALLY | اختبار قبول حقيقي بتصدير ffmpeg + ffprobe + فحص محتوى البكسل ناجح بالكامل (13/13 فحصًا؛ `scripts/arabic_acceptance.py`). |
| التعرف الصوتي (ASR) على كلام عربي حقيقي | NOT VERIFIED | لم يتوفر في هذه البيئة أي ملف صوتي/صوت عربي حقيقي لتشغيل اختبار قبول ASR مباشر؛ منطق الحفاظ على اللهجة نفسه مغطّى باختبارات انحدار آلية بدلًا من ذلك (حالات مصرية/خليجية/مختلطة). |
| رسوم Remotion المتحركة | FALLBACK AVAILABLE | تم اكتشاف Node/npm والتصدير ممكن عبر `npx`، لكن لم يُشغَّل ويُسجَّل أي تصدير قبول حقيقي في هذه البيئة (يعرض `videoedit doctor` "Verified: not yet"). |
| محرك HyperFrames | NOT VERIFIED | لا توجد حزمة HyperFrames حقيقية للتثبيت: الحزمة الوحيدة على PyPI بهذا الاسم هي مكتبة إطارات بيانات متعددة الأبعاد غير ذات صلة وبلا أي واجهة تصدير. موجّه الحركة (router) يتراجع بشكل صحيح إلى محرك يعمل (Simple/PIL) عند طلب HyperFrames وعدم توفره، وهذا التراجع مغطّى باختبار آلي ويُسجَّل دائمًا في `MotionPlanItem.fallback_log` — وليس استبدالًا صامتًا أبدًا. |
| تراجع محرك الحركة (HyperFrames/Remotion -> Simple) | VERIFIED LOCALLY | اختبار آلي يثبت أن المحرك غير المتاح يتراجع إلى محرك يعمل، وأن المشروع يكتمل، وأن كل محرك مرفوض يُسجَّل في `fallback_log` (`tests/test_motion_router.py`). |
| كشف قناع "خلف الموضوع" (Behind-Subject) والتخزين المؤقت | VERIFIED LOCALLY | تجزئة mediapipe حقيقية (غير وهمية) تعمل على مقطع فيديو حقيقي، والاستدعاء الثاني المطابق يعيد استخدام القناع المخزَّن بدلًا من إعادة حسابه (`scripts/behind_subject_acceptance.py`، `tests/test_behind_subject.py`). يتطلب `mediapipe<1.0` (مثل `mediapipe==0.10.21`) — الإصدار 1.0+ من mediapipe أزال الواجهة التي يستخدمها هذا المشروع. |
| تركيب فيديو "خلف الموضوع" (ظهور عنصر خلف الشخص فعليًا في الفيديو النهائي) | NOT VERIFIED | هذه فجوة معمارية حقيقية وليست مجرد ميزة غير مُختبَرة: `render/composition.py` لا يقرأ `Overlay.behind_subject` أبدًا، لذا لا يوجد أي مسار شيفرة في هذا المستودع يمكنه إنتاج هذه النتيجة البصرية حاليًا. فقط نصف الكشف/التخزين المؤقت أعلاه حقيقي. يوجد اختبار توصيف دائم يثبّت هذه الحقيقة حتى لا يُدَّعى "إصلاحها" لاحقًا بصمت. |
| ملفات الهوية التجارية (Brand Profiles) | VERIFIED LOCALLY | تأكد وصول الخطوط/الألوان/أنماط الترجمات المرتبطة بالهوية التجارية إلى خط التصدير الفعلي. |
| الوضع دون اتصال (بدون مفاتيح API) | VERIFIED LOCALLY | كل من `videoedit edit --offline` و`videoedit create --offline` و`videoedit assemble --offline` ينتج `final.mp4` صالحًا من البداية للنهاية بدون أي اتصال شبكي. |
| الانتقالات المرئية الحقيقية (قطع مباشر، تلاشٍ متقاطع قصير، مزج تدريجي) التي يصدّرها Assembler | VERIFIED LOCALLY | خطة موجّه الانتقالات (Transition Director) تُصدَّر فعليًا عبر مرشِّح ffmpeg `xfade` (الفيديو) — لا يُبلَّغ عن انتقال بأنه `applied=true` إلا إذا أنتج المصدِّر فعليًا ذلك التأثير. اختبار قبول التلاشي المتقاطع يتحقق من أن مدة المخرج تعكس التداخل وأن الإطارات الوسيطة تحتوي فعليًا على مزج بصري حقيقي، وليست قطعًا مباشرًا (`tests/test_phase2_transitions_loudness.py`). المزج التدريجي (Dissolve) يستخدم نفس آلية `xfade` المستخدمة في التلاشي المتقاطع القصير عن قصد — لا يوجد تأثير مختلف جوهريًا يستحق تطبيقًا منفصلاً. |
| تلاشي الصوت المتقاطع المصاحب لتلاشٍ مرئي متقاطع | VERIFIED LOCALLY | عندما يحتوي المقطعان على جانبي التلاشي المرئي المتقاطع على صوت حقيقي، يُطبَّق مرشِّح ffmpeg `acrossfade` لتفادي أي نقرة أو قفزة مفاجئة في مستوى الصوت؛ وإذا احتوى جانب واحد فقط على صوت حقيقي، يتراجع الصوت إلى دمج بسيط (concat) بدلًا من فرض تلاشٍ متقاطع. |
| تطبيع مستوى الصوت (Assembler) | VERIFIED LOCALLY | تطبيع محافظ قائم على `loudnorm`: تُطبَّع فقط المشاهد التي تنحرف عن المستوى المستهدف، ويُترك الصمت الرقمي الحقيقي دون تعديل (تجنبًا لعطل معروف في `loudnorm` ينتج قيم NaN عند إدخال صمت خالص)، ويسجَّل لكل قرار ما إذا كان التطبيع مطلوبًا/مطبَّقًا وعند أي مستوى مستهدف. اختبار القبول يتحقق من عدم وجود تشويه (clipping) في التصدير النهائي (`tests/test_phase2_transitions_loudness.py`). |
| قصّات J-Cut / L-Cut (تقديم/تأخير الصوت عن الصورة) | NOT IMPLEMENTED | مفهوم نظري فقط — موجّه الانتقالات لا يقترحه أبدًا. تأجيل متعمَّد لما بعد v0.2.0؛ ليس عائقًا أمام الإصدار. |

## الأسرار

`GEMINI_API_KEY` و `ELEVENLABS_API_KEY` تُقرأ فقط من متغيرات البيئة. لا تُكتب
أبدًا في ملف إعدادات، ولا تُسجَّل، ولا تُطبع أبدًا من أي أمر، بما في ذلك
`doctor`.

## ملفات الهوية التجارية (Brand Profiles)

تعيش الهويات التجارية كمجلدات عادية تحت `brands/<name>/` (الألوان، الخطوط،
قائمة الكلمات الممنوعة، محرك الرسوم المتحركة المفضل، نمط الترجمات). لا حاجة
لتعديل الشيفرة المصدرية لإضافة واحدة:

```bash
videoedit brand init my_brand
videoedit brand validate my_brand
videoedit edit my_take.mp4 --brand my_brand
```
